# Custody Services Agreement — Standing Instructions
## Client: Vantage Sovereign Investment Authority (sovereign wealth)

## 1. Standing election instruction
Notwithstanding POL-004 §6, where Harborline does not receive a specific instruction from Vantage for a voluntary event before the client response deadline, Harborline must apply the client's **standing instruction** rather than the issuer default:

| Event type | Standing instruction |
|---|---|
| DIVIDEND_OPTION | Elect **cash** |
| RIGHTS_ISSUE | **Sell rights** in the market where tradeable; otherwise lapse |
| TENDER_OFFER | **Do not tender** |

## 2. Consequence
Applying the issuer default instead of the standing instruction is treated as a missed election and compensated under POL-004 §8.
